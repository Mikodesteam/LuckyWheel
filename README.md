# LuckyWheel: Android spin wheel demo app (Java)

**A sample Android app with a lucky wheel / spin wheel / wheel of fortune screen**: colourful segments, custom text per item and a spin animation that lands on a chosen prize. Useful as a starting point for reward, giveaway and gamification screens in Android apps.

## What is inside

- `app/`: a demo app (splash screen + lucky wheel screen) written in Java.
- `luckyWheel/`: the wheel view module (`LuckyWheelView`, `PielView`, `LuckyItem`).

## How to run

1. Open the project in Android Studio.
2. Let Gradle sync.
3. Run the `app` configuration on an emulator or a phone.
